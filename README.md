# AdminRecoveryTool - Multi-User System

Multi-user administration tool with remote authentication for Windows.

## PERSONAL USE ONLY
This tool is for **PERSONAL USE ONLY** on your own devices.

## User Accounts

### Secret-user
- Password file: `Sec-User-Pass.txt` in private repo
- Full access to all features
- Main user account

### MrSecret
- Password file: `MrSecret-Access.txt` in private repo
- Full access to all features
- Additional user for later use

Both users have **identical access** to all features.

## Password System

Passwords are stored remotely in a private GitHub repository:
- **Online**: Fetches latest password from repo
- **Offline**: Uses last cached password
- **First time**: Requires internet connection
